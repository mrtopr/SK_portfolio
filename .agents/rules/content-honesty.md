# Content honesty

- Use only facts from `content/profile.json`. Rewording for clarity is fine; adding claims is not.
- Do not upgrade claims. "In active development" stays "in active development". "~60% in testing" keeps "in testing" next to it.
- Every number shown on the site must trace to a field in profile.json.
- If a link is `null`, do not render a dead button. Hide it and list it in the TODO report.
- Case study copy explains the problem, the decision, and the trade-off. It never just lists technologies.
- Photography and video: use only files I place in `public/media/`. Do not generate or source images.
