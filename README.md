## About

My personal portfolio — built to show what I actually build, how I think about engineering problems, and the measurable outcomes behind each project.

Built with **Next.js 14 App Router**, **TypeScript**, **Tailwind CSS**, and deployed on **Vercel**. Features scroll-driven architecture deep-dives for my two flagship projects: **SentinelLink** and **EduArchive**.

## Running Locally

```bash
git clone https://github.com/mrtopr/SK_portfolio.git
cd SK_portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

---

## Deployment

Deployed on **Vercel** via GitHub integration. Every push to `main` triggers an automatic production deploy.

```bash
npm run build   # validate production build locally
```
